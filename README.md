# Mind Code

This is the public issue tracker for [Mind Code](https://mindcode.sh) — an
agentic coding assistant for your terminal.

**No product source lives here.** This repository exists so that bug reports and
feature requests are public, searchable and de-duplicated. The product itself is
closed source.

## Report something

| What | Where |
|---|---|
| A bug | [Open a bug report](https://github.com/mind-code-ai/mind-code/issues/new?template=bug_report.yml) |
| An idea | [Request a feature](https://github.com/mind-code-ai/mind-code/issues/new?template=feature_request.yml) |
| Billing, invoices, refunds | Your [dashboard](https://app.mindcode.sh) — never a public issue |
| Security vulnerability | See [SECURITY.md](SECURITY.md) — never a public issue |

Before opening a bug, please
[search existing issues](https://github.com/mind-code-ai/mind-code/issues?q=is%3Aissue).
A comment on an existing report is more useful than a duplicate.

## Documentation
