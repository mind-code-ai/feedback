# Security policy

**Do not report security vulnerabilities in a public issue.**

A public issue tells everyone about the weakness before there is a fix, including
people who would use it. Report it privately instead:

- Use GitHub's [private vulnerability
  reporting](https://github.com/mind-code-ai/feedback/security/advisories/new)
  on this repository, or
- email **security@mindcode.sh**

Please include what you did, what happened, and what you expected. If you have a
proof of concept, describe it rather than attaching a working exploit.

We will acknowledge your report, tell you whether we can reproduce it, and let
you know when a fix ships. We will credit you unless you would rather we did not.
